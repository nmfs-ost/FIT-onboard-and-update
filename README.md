# onboard-and-update
Request update a tool in the NOAA FIT by submitting an [issue](https://github.com/noaa-fisheries-integrated-toolbox/onboard-and-update/issues)

For onboarding, please see the [FIT-review-and-onboard repository](https://github.com/nmfs-ost/FIT-review-and-onboard)

# Admin instructions

## Token

A fine-grained token is used in the github action to read and write to issues using the GitHub API. The token needs read and write permissions for issues in the FIT-onboard-and-update repository.

The fine grain token was added as a repository-level secret for use in the GitHub action.
